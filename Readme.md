A collection of ready-to-use templates, notebooks, and tutorials for building stateful AI agents and workflows with LangGraph.

Core Topics:

Agents: Chatbots, ReAct agents, multi-agent systems, and code assistants.

Workflows: RAG, reflection, human-in-the-loop (HITL), and self-discover patterns.

Memory & Persistence: Database integrations (MongoDB, Postgres, Redis) and time-travel debugging.

Core Capabilities: Tool calling, streaming tokens/events, and complex state management.

Target Audience: Developers looking to learn, test, and deploy multi-actor LLM applications quickly.
